Самодостаточный дашборд для глубокого анализа трафика и поведения посетителей на веб-проектах. Система собирает данные через встраиваемый трекер, обрабатывает на сервере и визуализирует в интерактивном интерфейсе с 12 разделами — от общей статистики до реального времени и конверсий. Встроенный ИИ-ассистент помогает интерпретировать показатели и отвечать на вопросы по аналитике.

### Что внутри

Панель состоит из 12 разделов, каждый из которых покрывает отдельный аспект веб-аналитики:

- **Обзор** — сводная информация: уникальные посетители, просмотры, средняя длительность сессии, показатель отказов, динамика посещений по дням, топ стран, устройства и источники трафика
- **Реальное время** — активные посетители прямо сейчас, текущие страницы и события, поток событий с автоматическим обновлением каждые 5 секунд
- **Посетители** — список уникальных посетителей: кто заходил, человек или бот, откуда, когда, сколько раз; разделение на новых и возвращающихся
- **Проекты** — управление подключёнными сайтами: статистика, рейтинги, код подключения трекера, автообнаружение новых проектов
- **География** — географическое распределение посетителей: страны, города, регионы с визуализацией на карте
- **Устройства** — устройства, браузеры, ОС и разрешения экранов посетителей; детальное сравнение десктоп/ноутбук/мобильный/планшет
- **Источники трафика** — откуда приходят посетители: прямые переходы, поисковые системы, социальные сети, рефералы, UTM-метки
- **Конверсии** — воронка конверсии, цели и достижения; настройка триггеров для отслеживания ключевых действий
- **Сравнение** — параллельное сравнение показателей двух проектов между собой
- **Страницы** — статистика по каждой странице: просмотры, уникальные посетители, среднее время, показатель выходов
- **Отчёты** — экспорт данных в CSV и JSON, автоматическая генерация отчётов за выбранный период
- **Настройки** — подключение трекера, управление API, роли пользователей, уведомления

### Трекер и сбор данных

Встраиваемый JavaScript-трекер (`tracker.js`) подключается к любому сайту одной строкой и собирает расширенный набор данных:

- **Идентификация посетителей** — Canvas + WebGL фингерпринтинг, уникальный userId, сессионные ключи с таймаутом 30 минут
- **Определение ботов** — расширенная клиент-серверная детекция: парсинг User-Agent по 50+ паттернам (Googlebot, YandexBot, GPTBot, SemrushBot, AhrefsBot и др.), анализ автоматизационных сигналов (webdriver, PhantomJS, NightmareJS, Selenium, Puppeteer)
- **Поведенческие сигналы** — подсчёт движений мыши, нажатий клавиш, тач-событий, скроллов, кликов; расчёт interaction score (0–5) для различения людей и ботов
- **Геолокация** — определение страны, города и региона по IP через ipapi.co
- **UTM-параметры** — автоматический сбор utm_source, utm_medium, utm_campaign, utm_content, utm_term
- **Тип устройства** — эвристика для различения desktop/laptop/mobile/tablet с учётом DPR и специфичных разрешений MacBook
- **SPA-навигация** — перехват pushState/replaceState и popstate для корректного отслеживания страниц в Single Page Applications
- **Глубина скролла** — отслеживание прокрутки страницы с отправкой процентных значений
- **Время на странице** — фиксация через visibilitychange и beforeunload

### ИИ-ассистент

Встроенный чат-ассистент с потоковым выводом ответов помогает анализировать данные аналитики. Ассистент поддерживает выбор модели через OpenRouter API, предлагает типовые вопросы для быстрого старта и имеет панель тестирования доступности моделей.

### Стек

- **Frontend**: Next.js 16, React 19, TypeScript, Tailwind CSS 4, shadcn/ui
- **База данных**: PostgreSQL (Neon Serverless), Prisma ORM
- **Визуализация**: Recharts (AreaChart, BarChart, PieChart)
- **AI**: OpenRouter API — потоковый вывод ответов, выбор моделей
- **Аутентификация**: NextAuth.js
- **State**: Zustand
- **Деплой**: Vercel
