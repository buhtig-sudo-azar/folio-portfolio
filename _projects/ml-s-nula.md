Интерактивный курс для тех, кто только начинает разбираться в машинном обучении. Десять модулей с живыми песочницами на JavaScript: покрути веса, посмотри, как меняется ошибка, пройди цикл обучения и пойми, почему модель ведёт себя именно так. Никакой магии — только числа, которые меняются.

### О чём этот курс

Большинство материалов по машинному обучению начинаются с формул и быстро уходят в математику. Этот курс идёт от обратного: сначала интуиция через взаимодействие, потом — название. Песочницы дают возможность потрогать концепции руками: передвинул вес — ошибку пересчитало, поменял данные — модель переобучилась. Прогресс сохраняется в браузере, ответы никуда не уходят, всё работает офлайн после первой загрузки.

### Модули курса

1. **Термины** — признаки, веса, метки: базовый словарь, без которого ничего не поймёшь
2. **Веса** — как модель «взвешивает» признаки и почему одни сигналы важнее других
3. **Ошибка** — как модель понимает, что ошиблась, и какие функции потока используются
4. **Обучение** — градиентный спуск без формул: шаг за шагом к минимуму ошибки
5. **Данные** — почему данные решают всё: качество, репрезентативность, смещения
6. **Будущее** — переобучение и регуляризация: когда модель запоминает, а не учится
7. **Цикл обучения** — итерации и сходимость: сколько раз нужно пройти по данным
8. **Спам-фильтр** — практический пример: собираем простую модель для классификации
9. **Объяснимость** — почему модель так решила: интерпретация предсказаний
10. **Что дальше** — roadmap для развития: куда идти после основ

### Что внутри

- **10 живых песочниц** на React + TypeScript — каждая концепция сопровождается интерактивом
- **Прогресс сохраняется** локально в `localStorage` — можно вернуться и продолжить
- **Светлая и тёмная тема** с плавной инверсией цветов и переключателем в углу
- **Кнопка-мозг «наверх»** с пульсирующей анимацией
- **32 курируемых бесплатных ресурса** для дальнейшего изучения
- **Адаптивный дизайн** — работает на мобильных и десктопах
- **Доступность**: keyboard-friendly, `aria-label`, поддержка `prefers-reduced-motion`

### Стек технологий

- **Frontend**: Next.js 16 (App Router, Turbopack), React 19, TypeScript
- **Стили**: Tailwind CSS 4 + shadcn/ui, токены тем через CSS-переменные
- **Иконки**: lucide-react
- **Хранилище прогресса**: `localStorage` (без серверной части)
- **Деплой**: Vercel
