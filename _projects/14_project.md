Полноценная обучающая экосистема для погружения в AI-инжиниринг, построенная вокруг принципа **«ALL IS SKILL»** — каждый элемент системы является навыком или композицией навыков. Платформа охватывает весь конвейер: от промпт-инжиниринга до оркестрации мультиагентных workflows, от RAG-пайплайнов до MCP-интеграций.

### Архитектура платформы

В основе лежат 11 специализированных модулей, каждый из которых отвечает за отдельный аспект обучения и практики:

- **Skill Engine** — ядро системы: создание, версионирование и валидация навыков в формате SKILL.md (YAML frontmatter + Markdown)
- **Lesson Engine** — 6-секционные уроки: введение → теория → диаграмма → примеры → песочница → типичные ошибки
- **Sandbox Engine** — 7 типов интерактивных песочниц: Prompt, Agent, Tool, MCP, RAG, Workflow, Architecture
- **Chatbot Engine** — 7 ИИ-наставников с уникальными персоналиями и экспертными знаниями по каждому направлению
- **Agent Engine** — конструктор агентов из навыков с декларативным описанием инструментов
- **Workflow Engine** — визуальный оркестратор: связывание навыков и агентов в исполняемые цепочки
- **MCP Engine** — управление Model Context Protocol серверами и их инструментами
- **RAG Engine** — конвейер Retrieval-Augmented Generation: базы знаний, чанкинг, эмбеддинги, поиск
- **Model System** — мультипровайдерная маршрутизация моделей с fallback на свободные через OpenRouter
- **Security Engine** — правила безопасности, валидация ввода-вывода, мониторинг и логирование
- **Admin Panel** — конфигурация платформы, управление контентом и аналитика

### Образовательная модель

Обучение строится по пути: **Урок → Песочница → Валидация → Навык → Агент → Workflow**. Студент сначала осваивает теорию через структурированный урок, затем закрепляет в интерактивной песочнице, проходит валидацию и получает навык. Навыки компонуются в агенты, агенты — в workflows. Два режима работы: **образовательный** (полная симуляция, песочницы вместо API) и **продвинутый** (реальные API опционально).

### Визуализация и диаграммы

Каждый урок сопровождается интерактивной диаграммой одного из 6 типов: потоковая (flow), древовидная (tree), графовая (graph), причинно-следственная (cause-effect), дерево атак (attack-tree), карта знаний (knowledge-map). Диаграммы помогают визуально освоить архитектуры и взаимосвязи компонентов.

### ИИ-компаньоны

Семь специализированных наставников сопровождают обучение по каждому разделу:

- **Скилл-мастер** — эксперт по навыкам и их композиции
- **Агент-архитектор** — проектирование и сборка агентов
- **Промпт-инженер** — искусство промпт-инжиниринга
- **Песочница-проводник** — навигация по практическим заданиям
- **Оркестратор** — управление workflows и цепочками вызовов
- **MCP-навигатор** — интеграция с Model Context Protocol
- **RAG-исследователь** — построение конвейеров поиска и генерации

### Мотивационная система

Встроенная геймификация поддерживает вовлечённость: накопление XP, повышение уровня, серии дней, уникальные достижения за прохождение разделов и эксперименты в песочницах.

### Технологический стек

- **Frontend**: Next.js 16, React 19, TypeScript, Tailwind CSS 4, shadcn/ui, Zustand
- **База данных**: SQLite, Prisma ORM
- **AI**: OpenRouter API — мультипровайдерная маршрутизация с потоковым выводом
- **Деплой**: Vercel
