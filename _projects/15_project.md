Образовательная платформа для интерактивного изучения системного администрирования, DevOps-инженерии и облачной инфраструктуры. Все материалы на русском языке, актуальны на июнь 2026 года. Встроенный ИИ-наставник с поддержкой бесплатных LLM-моделей через OpenRouter.

### Что представляет собой проект

Ресурс превращает 20 тематических направлений — от основ Linux до облачной безопасности — в структурированный веб-опыт. Каждая категория содержит вопросы трёх уровней сложности с детальными ответами и AI-объяснениями. Персональный чат-ассистент готов ответить на любые вопросы по тематике раздела.

### Тематические направления

Платформа охватывает полный спектр знаний, необходимый современному системному администратору:

- **Linux** — ядро, процессы, файловые системы, systemd, пакетный менеджмент
- **Системное администрирование** — управление пользователями, cron, логирование, загрузчики, бэкап-стратегии
- **Сети** — TCP/IP, DNS, BGP, NAT, файрволы, VPN
- **Bash** — скриптинг, обработка текста, переменные, автозадачи
- **Безопасность** — харденинг, SELinux, PAM, TLS 1.3, руткиты
- **Хранилище данных** — MBR/GPT, RAID, LVM, ZFS, NFS, iSCSI, Stratis
- **Серверы** — Nginx, BIND, DHCP, PostgreSQL, Samba, Postfix
- **Docker** — контейнеризация, Dockerfile, Compose, сети, volumes
- **Kubernetes** — архитектура, поды, Gateway API, StatefulSet
- **Terraform** — IaC, HCL, state management, OpenTofu
- **Ansible** — плейбуки, роли, инвентарь, автоматизация
- **AWS / Azure / GCP** — облачная архитектура, IAM, сети
- **DevOps** — CI/CD, GitOps, SRE, управление релизами
- **Мониторинг** — Prometheus, Grafana, OpenTelemetry, алертинг
- **Базы данных** — PostgreSQL, Redis, оптимизация, репликация
- **Веб-серверы** — Nginx, Apache, балансировка, SSL/TLS
- **eBPF** — наблюдаемость ядра, bpftrace, XDP, Cilium
- **Облачная безопасность** — IAM, WAF, комплаенс, постквантовая криптография

### ИИ-наставник

Каждая категория оснащена специализированным чат-ассистентом с потоковым выводом ответов. Система поддерживает:

- Выбор из 20+ бесплатных LLM-моделей через OpenRouter
- Добавление собственного API-токена OpenRouter
- Проверку доступности и задержки каждой модели
- Подключение кастомных моделей
- Автоматический фолбэк при недоступности модели

### Режимы обучения

- **Обучение** — изучение вопросов по категориям с AI-объяснениями трёх уровней: для новичков, среднего и продвинутого уровня
- **Собеседование** — тренировка перед техническими интервью с рандомизированными вопросами
- **ИИ-наставник** — свободный чат с экспертом по выбранной теме
- **Прогресс** — система XP и уровней от Новичка до Архитектора

### Стек технологий

- **Frontend**: Next.js 16, React 19, TypeScript, Tailwind CSS 4, shadcn/ui
- **База данных**: Prisma ORM (SQLite для разработки, PostgreSQL для продакшена)
- **AI**: OpenRouter API — потоковый вывод, выбор моделей, rate-limit мониторинг
- **State**: Zustand с localStorage-персистентностью
- **Деплой**: Vercel, GitHub
